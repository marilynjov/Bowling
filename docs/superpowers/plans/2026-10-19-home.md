# Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder Home with Resume, Start session, Quick score with Undo, the Home preset's stat tiles, and the three most recent sessions.

**Architecture:** Plain values carry the logic and are unit tested: `QuickScoreEntry` (the score field), `HomeTiles` (reports to tile contents), and `HomeData` (one load from the store: tiles with their scope, the resume card, recent rows). `AppModel` gains the selected tab, `resume`, and quick score with its undo state. SwiftUI views render those values; the root presents the Quick score sheet like the New session sheet.

**Tech Stack:** SwiftUI, Swift Testing, BowlingData (`SessionRepository`, `BowlerRepository`, `StatsRepository`, `GameRepository` in tests), BowlingCore (`StatsEngine`, `StatsPreset`, `Scorer`, `StatsReport`).

**Spec:** `docs/superpowers/specs/2026-10-19-home-design.md`

## Global Constraints

- iOS 18 minimum; `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` and member import visibility: import every module whose types a file uses.
- Contract only: `owner()`, `sessions()`, `resumableSession()`, `quickScore(finalScore:now:)`, `deleteSession(_:)`, `stats.games(matching:now:calendar:)`, `stats.defaultEventTypes(for:preferCompetition:)`, `StatsEngine.report(games:filter:)`, `StatsPreset.displayedHomeTiles(layout:profile:)`, `StatsPreset.prefersCompetition(_:)`, `Scorer.nextRoll(in:)`. No package changes.
- Uses #5's `StatTile` and `StatFormat` unchanged (merged into the branch at `2c123f0`).
- D1 colors only through asset symbols (`.canvas`, `.surface`, `.hairline`, `.ink`, `.inkMuted`, `.accent`, `.accentText`).
- Copy exactly as the spec: "Home", "Resume", "Start session", "Quick score", "Cancel", "Save", "Saved as a casual game today. You can change it in History.", "Saved <score>", "Undo", "Recent sessions", "Your sessions show up here.", "Game <n>", "Game <n> · frame <f>", "All games <avg>", tile titles "Average", "High game", "High series", "Strike %", "Spare %", "Fouls". Event titles "Practice", "League", "Tournament", "Casual".
- Previews are `#if DEBUG`: light, dark, AX5.
- Tests run on iPhone 18 Pro Max (`id=2C568C51-3721-4FB2-90EE-D54EB3308C03`) with `-parallel-testing-enabled NO`, never the iPhone 18 Pro. Tests use `BowlingStore(inMemory: true)` and `UserDefaults(suiteName: "test.\(UUID())")!`.

Test command (whole suite): `xcodebuild test -scheme Bowling -destination 'id=2C568C51-3721-4FB2-90EE-D54EB3308C03' -parallel-testing-enabled NO`. One suite: add `-only-testing:BowlingTests/<Suite>`.

## Review Focus

1. Undo tapped twice, or after a second quick score: only the latest quick score is deleted, once — Task 4 tests `undoTwiceDeletesOnce`, `secondQuickScoreReplacesTheUndo`.
2. A quick score while a session is unfinished: Resume still points at the unfinished session — Task 3 test `quickScoreKeepsResumeOnTheUnfinishedSession`.
3. A friend ahead of the owner in the lineup: Resume opens the friend's unfinished game, and the recent row shows only the owner's scores — Task 3 tests `resumeFollowsLineupOrder`, `recentRowListsOnlyTheOwnersScores`.
4. A league bowler whose games are all practice: tiles use all games and the Average has no "All games" line — Task 3 test `noCompetitionGamesFallsBackToAllGames`.
5. Typed scores like "0300" or "300 " — rejected, so Save stays disabled — Task 1 test `rejectsBadText`.

Rulings against the spec, already applied to it: the current frame comes from `Scorer.nextRoll(in:)` (counting frames with a roll is off by one mid-frame); "All games 168" goes on the Average tile's sample line after its game count, because `StatTile` has one sample line and #5 isn't changed here.

# Ball Add and Edit Form Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One sheet adds a ball or edits every field, sets its photo, and retires or deletes it.

**Architecture:**
- `BallForm` is a value type holding the form's state. It turns into `BallFields`, then saves itself and its photo change.
- `BallPhoto` shrinks a picked image to a JPEG.
- `AppModel` owns which sheet is open (`ballForm: BallFormTarget?`) and the save, retire and delete actions.
- `BallFormSheet` is the SwiftUI view. Tapping an Arsenal row opens it in Edit until #30.

**Tech Stack:** SwiftUI iOS 18, Swift 6, PhotosUI `PhotosPicker`, UIKit `UIImage`/`UIGraphicsImageRenderer`, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-11-01-ball-form-design.md`

## Global Constraints

- **Packages:** never edit `Packages/`. Use contract §3.6 as is:
  - `addBall(_:)`, `updateBall(_:with:)`, `detail(for:)`
  - `setPhoto`, `removePhoto`, `photo(for:)`
  - `setRetired`, `deleteBall`
  - `maxPhotoBytes`
- **Required fields:** only name and weight. Weight runs 6–16 lb.
- **Photo:** at most 1024 px on the longest side, never upscaled, JPEG at quality 0.8.
- **Copy, exactly:**
  - Titles: "Add ball", "Edit ball"
  - Surface prompt: "Same as factory finish"
  - Field errors: "Enter a number", "Enter a whole number of at least 1"
  - Photo error: "Couldn't use that photo."
  - Edit buttons: "Retire ball", "Return to arsenal", "Delete ball"
  - Delete confirmation: "Delete this ball? Its photo and maintenance log are deleted too."
- **Fixed copy goes through `String(localized:)`** when passed as a `String` (the #14 rule).
- **No Co-Authored-By trailer** in commits.
- **Unit tests:** `xcodebuild test -scheme Bowling -destination 'id=2C568C51-3721-4FB2-90EE-D54EB3308C03' -parallel-testing-enabled NO -only-testing:BowlingTests/<Suite>`.
  - Run full-suite runs in the background.
  - Kill a hung xcodebuild by PID.
  - On "Failed to create a bundle instance", rerun.

## Review Focus

1. **A comma decimal locale.** With `es_ES`, "2,52" must parse as 2.52, and Edit must show 2.52 as "2,52". Test: `parsesTheLocaleDecimalSeparator` (Task 2).
2. **Blanking a field on Edit must clear it.** Since `updateBall` replaces every field, a blanked RG saves as nil. Test: `blankedNumberClearsOnEdit` (Task 2).
3. **A photo that fails after the ball saved.** The ball is kept and the error propagates. Test: `photoFailureKeepsTheBall` (Task 2), using data over `maxPhotoBytes`.
4. **Editing a retired ball keeps it retired.** Test: `editKeepsRetired` (Task 2).
5. **A panorama photo**, very wide and short, scales by its longest side and stays under `maxPhotoBytes`. Test: `panoramaScalesByLongestSide` (Task 1).

### Task 2: BallForm

**Files:**
- Create: `Bowling/Features/Arsenal/BallForm.swift`
- Test: `BowlingTests/Arsenal/BallFormTests.swift`

**Interfaces:**
- Produces:

```swift
struct BallForm: Hashable {
    enum PhotoChange: Hashable { case unchanged, set(Data), removed }
    enum NumberField: CaseIterable { case rg, differential, intermediateDifferential, resurfaceInterval }
    struct InvalidNumber: Error {}
    var editing: BallID?            // nil on add
    var isRetired: Bool             // false on add
    var name, brand, colorDescription, serialNumber, coverstockName, coreName,
        factoryFinish, surfaceGrit, notes: String
    var weightPounds: Int?
    var coverstock: Coverstock; var coreType: CoreType; var intendedRole: BallRole
    var releaseDate, purchaseDate: Date?
    var rg, differential, intermediateDifferential, resurfaceInterval: String   // as typed
    var photo: PhotoChange
    var locale: Locale              // .current; tests pass one
    init(locale: Locale = .current)
    init(editing id: BallID, detail: BallDetail, locale: Locale = .current)
    var canSave: Bool
    func fieldError(_ field: NumberField) -> String?
    func fields() -> BallFields?
    /// Throws `.invalidBall(.weightOutOfRange)` with no weight, `InvalidNumber` for a bad number,
    /// else what the repository throws.
    func save(to store: BowlingStore) throws -> BallID
}
```

- [ ] **Step 1: Write the failing tests.** Port `BallDraftTests` into this suite. `fullDetail()` is a helper that adds a ball with every `BallFields` value set, through `addBall(_:)`.

```swift
@Test func cantSaveWithoutANameOrWeight()  // as BallDraftTests, plus a valid form with rg "abc" → !canSave
@Test func editRoundTripsEveryField()      // BallForm(editing:detail:).fields() == detail.fields
@Test func blankNumbersAreNil()            // rg "" → fields()?.rg == nil; resurfaceInterval "" → nil
@Test func badNumbersHaveMessages()        // rg "abc" → "Enter a number"; resurfaceInterval "0" and "2.5" → "Enter a whole number of at least 1"; valid → nil
@Test func parsesTheLocaleDecimalSeparator() // es_ES: rg "2,52" → 2.52; editing rg 2.52 → form.rg == "2,52"
@Test func intermediateDifferentialNeedsAsymmetric() // coreType .symmetric, text "0.015" → nil; .asymmetric → 0.015
@Test func factoryFinishSeedsTheSurfaceOnAdd() // factoryFinish "1500 Abralon", surfaceGrit "" → detail.fields.surfaceGrit == "1500 Abralon"
@Test func editChangesOnlyThatField()      // edit name only; every other field equal to before
@Test func blankedNumberClearsOnEdit()     // ball with rg 2.5; form.rg = "" → detail rg == nil
@Test func unknownRoleIsKept()             // form.intendedRole = .unknown on edit → stored role unchanged
@Test func editKeepsRetired()              // setRetired(true); edit and save → detail.isRetired
@Test func photoChangesApply()             // .set → photo(for:) == data; .removed → nil; .unchanged → kept
@Test func photoFailureKeepsTheBall()      // add with .set(Data(count: maxPhotoBytes + 1)) → throws .invalidBall(.photoTooLarge); activeBalls().count == 1
@Test func savedBallIsInNewSessionsBalls() // ported
```

- [ ] **Step 2: Run them.** Expected: FAIL, because `BallForm` doesn't exist yet.
- [ ] **Step 3: Implement `BallForm`.**
  - **Numbers:** parse with `FormatStyle` (`Double.ParseStrategy` and `IntegerFormatStyle` in `locale`). Format with `.number.locale(locale)` and no grouping.
  - **Edit role:** `.unknown` passes through as is, since the package keeps the stored role.
  - **`save`:**
    - Edit calls `updateBall`; Add calls `addBall(_:)`.
    - Then apply `photo`: `setPhoto` for `.set`, `removePhoto` for `.removed`.
- [ ] **Step 4: Run them.** Expected: PASS.
- [ ] **Step 5: Commit** `feat: BallForm model for add and edit (#29)`.

- [ ] **Step 1: Build the sheet** from spec §2, §4 and §5.
  - `init(target: BallFormTarget)` loads `detail(for:)` on edit.
  - Number fields show `fieldError` below them in `.cautionText`.

    - show the picked image or the stored photo, else the placeholder
    - `PhotosPicker` labelled "Choose photo" or "Change photo"
    - "Remove photo" when there is a photo
    - a picked item loads with `loadTransferable(type: Data.self)`, then goes through `BallPhoto.downscaled`; nil shows "Couldn't use that photo." under the row
  - Add `.sharedErrorAlert(in: .ballForm)`.

# Stats Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Stats tab: a filter bar (date preset, games scope, bowler) and the bowling
style's cards from a `StatsReport`, each with its sample, with an explanation on cards
whose games don't apply.

**Architecture:** Pure value types (`StatTileContent`, `StatsCards`, `StatsFilterDraft`)
turn the report and filter into text and are unit tested; views only render them. Home's
`HomeTiles` moves onto the shared tile mapping so both screens word numbers the same.

**Tech Stack:** SwiftUI (iOS 18, `@Observable`, MainActor default isolation), Swift
Charts, Swift Testing, BowlingCore/BowlingData contract.

**Spec:** `docs/superpowers/specs/2026-10-27-stats-design.md`

## Global Constraints

- The app talks to packages only through the contract (AGENTS.md). No package edits;
  `Packages/` is Santiago's.
- Stats only reads; nothing on this screen writes.
- Copy is fixed by the spec: chips "This week", "This month", "Last 30 days", "This
  season", "All time", "Competition", "All games", custom types in the order Practice,
  League, Tournament, Casual joined by ", "; sheet "Filters", "Date", "Games", "Custom",
  "Bowler", "Cancel", "Done"; not-applicable "No complete games yet.", "Enter frames to see
  strikes and spares.", "Enter pins to see leaves."; "Coming soon."; "Left most, made
  least", "No leave seen 3 times yet.", "Made 7 of 9", "Show all N leaves", "12 sessions",
  "Last 10 201 · Last 30 195".
- Card titles: "Average", "High game", "High series", "Trend", "Strike %", "Spare %",
  "Fouls", "Open %", "Clean games %", "First-ball average", "Head pin %", "Leaves", "Left
  most, made least", "Split conversion %", "Makeable conversion %", "Single-pin conversion
  %", "Strikes by frame", "Average by frame", "What if".
- Sample lines come from the shared tile mapping, so they read as Home's do today ("210
  frames", "77 chances", "41 games"), plus two new units: "210 first balls", "9 leaves".
- VoiceOver strings live in `AccessibilityText` and are unit tested: "Trend, 12 sessions,
  latest session 201, rolling average 195"; "Leave 3, 6, 10, split, made 2 of 9".
- Each screen has Light, Dark and AX5 previews.
- Test command (never the iPhone 18 Pro named destination):
  `xcodebuild test -scheme Bowling -destination 'id=2C568C51-3721-4FB2-90EE-D54EB3308C03' -parallel-testing-enabled NO -only-testing:BowlingTests/<Suite> > .superpowers/sdd/2026-10-27-stats/<suite>.log 2>&1; tail -40 <log>`.
  A suite filter names one `@Suite` struct; check which struct a test lives in. If
  xcodebuild hangs after the tests pass, kill it by PID from `pgrep -x xcodebuild`, never
  `pkill -f`.
- Commits: no `Co-Authored-By` trailer.
- New app files in `Bowling/Features/Stats/`, new tests in `BowlingTests/Stats/`
  (synchronized folders, no pbxproj edits).

## Review Focus

1. A filter with no games at all (new owner, or "This week" on a quiet week): every card
   keeps its title and shows its not-applicable text, nothing crashes or shows "NaN".
   Task 2 tests an empty report for every catalog card.
2. A final-only bowler (score games but no rolls): overview cards render, strike/spare
   and leaf cards say "Enter frames…" / "Enter pins…". Task 2 tests it.
3. The filter's bowler deleted while the app runs: Stats falls back to the owner's default
   instead of showing a dead bowler. Task 3 tests it.
4. Custom scope with no event types picked must not be applied (it would match nothing
   and look like data loss). Task 3 tests `canApply`.
5. A layout holding an unknown card ID (newer app version) is skipped, not shown blank.
   `displayedStatsCards` already skips it; Task 2 tests `StatsCards.make` ignores nothing
   it is given and that the screen passes it the displayed list.

### Task 2: StatsCards

**Files:**
- Create: `Bowling/Features/Stats/StatsCards.swift`
- Modify: `Bowling/Components/AccessibilityText.swift`
- Test: `BowlingTests/Stats/StatsCardsTests.swift`, `BowlingTests/Components/AccessibilityTextTests.swift`

**Interfaces:**
- Consumes: `StatTileContent.make(_:_:)`.
- Produces:
  ```swift
  struct StatsCard: Hashable, Identifiable {
      enum Body: Hashable {
          case tile(StatTileContent, footnote: String?)
          case trend(TrendContent)
          case leaves([LeaveRowContent])
          case leftMost(LeaveRowContent?)
          case notApplicable(String)
          case comingSoon
      }
      var id: StatsCardID
      var title: String
      var body: Body
  }
  struct TrendContent: Hashable {
      var points: [TrendPoint]          // only points with a session average
      var sample: String                // "12 sessions" / "1 session"
      var accessibilityLabel: String
  }
  struct LeaveRowContent: Hashable {
      var leave: Leave
      var made: String                  // "Made 7 of 9"
      var rate: String                  // StatFormat.percent(conversion)
      var accessibilityLabel: String
  }
  enum StatsCards {
      static func make(cards: [StatsCardID], report: StatsReport, calendar: Calendar = .current) -> [StatsCard]
  }
  extension AccessibilityText {
      static func trend(sessions: Int, latest: String, rolling: String) -> String
      static func leaveRow(_ leave: Leave, made: Int, of count: Int) -> String
  }
  ```
  Rules (spec §3): group by card — score (`average`, `highGame`, `highSeries`,
  `trendChart`), roll (`strikePct`, `sparePct`, `fouls`, `openPct`, `cleanGamePct`,
  `firstBallAverage`), pin (`headPinRate`, `leavesTable`, `leftMostMadeLeast`, the three
  conversions); zero games in the group → `.notApplicable` with that group's copy.
  `byFrameStrike`, `byFrameAverage`, `whatIfSinglePins` → `.comingSoon` always.
  `average` footnote: "Last 10 201 · Last 30 195", each part only when there are more
  than 10 / 30 games; nil otherwise. `highGame` / `highSeries` sample is the date
  (`.formatted(.dateTime.month(.abbreviated).day())`, e.g. "Oct 21"); "–" value keeps the
  games sample. Leaves: all rows in report order (the view shows 10 and "Show all").

- [ ] **Step 1: Write the failing tests.**
  - `everyPresetCardRendersForEachStyle` (Done-when): for each of `.casual`, `.league`,
    `.competitive`, `make(cards: StatsPreset.statsCards(for: profile), report: PreviewData.report)`
    → ids equal the preset; every card whose id is a 1a card has a body that is not
    `.notApplicable` and not `.comingSoon`.
  - `emptyReportExplainsEveryCard`: report from no games, all `StatsCardID.allCases`
    except the three later cards → each `.notApplicable`; titles unchanged.
  - `finalOnlyGamesShowOverviewOnly`: report from complete final-only games →
    `average` is `.tile`, `strikePct` is `.notApplicable("Enter frames to see strikes and spares.")`,
    `leavesTable` is `.notApplicable("Enter pins to see leaves.")`.
  - `laterCardsAreComingSoon`: the three → `.comingSoon` with titles "Strikes by frame",
    "Average by frame", "What if".
  - `averageFootnoteNeedsMoreThanTenGames`: 10 games → footnote nil; 11 → "Last 10 …".
  - `leftMostNilHasNoLeave`: a pin report whose `leftMostMadeLeast` is nil → `.leftMost(nil)`.
  - `leaveRowText`: a row with conversion 7 of 9 → made "Made 7 of 9".
  - `AccessibilityTextTests.trendLabel`: `trend(sessions: 12, latest: "201", rolling: "195") == "Trend, 12 sessions, latest session 201, rolling average 195"`.
  - `AccessibilityTextTests.leaveRowLabel`: `leaveRow(PreviewData.leave(3, 6, 10), made: 2, of: 9) == "Leave 3, 6, 10, split, made 2 of 9"`.
- [ ] **Step 2: Run** `-only-testing:BowlingTests/StatsCardsTests -only-testing:BowlingTests/AccessibilityTextTests`.
  Expected: build fails on `StatsCards`.
- [ ] **Step 3: Implement** as in Interfaces. `leaveRow` reuses `AccessibilityText.leave(_:)`
  and appends ", made M of N".
- [ ] **Step 4: Run** the same command. Expected: all pass.

### Task 3: StatsFilterDraft

**Files:**
- Create: `Bowling/Features/Stats/StatsFilterDraft.swift`
- Modify: `Bowling/App/AppModel.swift` (`statsFilter`)
- Test: `BowlingTests/Stats/StatsFilterDraftTests.swift`

**Interfaces:**
- Produces:
  ```swift
  struct StatsFilterDraft: Hashable {
      enum Scope: Hashable { case competition, allGames, custom }
      var filter: StatsFilter
      var bowlerName: String
      /// The owner's default for `bowler`: allTime, and defaultEventTypes with the owner's
      /// statsScope / statsProfile preference.
      static func defaults(for bowler: BowlerRecord, owner: BowlerRecord, in store: BowlingStore) -> StatsFilterDraft
      /// The kept filter, or the owner's default when nil or its bowler is gone.
      static func current(_ kept: StatsFilterDraft?, in store: BowlingStore) -> StatsFilterDraft?
      var scope: Scope                  // from filter.eventTypes
      var chips: [String]               // [date, scope, bowler name]
      var canApply: Bool                // eventTypes not empty
      /// Same date; that bowler's default scope.
      func changingBowler(to bowler: BowlerRecord, owner: BowlerRecord, in store: BowlingStore) -> StatsFilterDraft
  }
  // AppModel
  var statsFilter: StatsFilterDraft?
  ```
  `current` returns nil only when there is no owner.

- [ ] **Step 1: Write the failing tests** (in-memory store; owner via `createOwner`, games
  via `NewSessionDraft.start` and `setFinalScore`, as in `ArsenalListTests`/`HomeDataTests`).
  - `leagueOwnerWithLeagueGamesStartsOnCompetition`: league owner, one complete league
    game → `scope == .competition`, chips `["All time", "Competition", "Sam"]`.
  - `casualOwnerStartsOnAllGames`: casual owner → `.allGames`, chip "All games".
  - `savedScopeWins`: league owner with `statsScope = .all` (`setStatsScope(.all)`) → `.allGames`.
  - `customChipListsTypesInFixedOrder`: `eventTypes = [.league, .practice]` → `scope == .custom`,

  - `datePresetChips`: each `DatePreset` → "This week", "This month", "Last 30 days",

  - `changingBowlerResetsTheScope`: from a custom scope, `changingBowler(to: friend…)` →

  - `deletedBowlerFallsBackToTheOwner`: kept draft for "Ana", delete Ana →
    `current(kept, in:)?.filter.bowlerID == owner.id`.

### Task 4: The Stats screens

**Files:**
- Create: `Bowling/Features/Stats/StatsFilterBar.swift`, `StatsFilterSheet.swift`, `StatsCardView.swift`, `TrendCard.swift`, `LeavesCard.swift`
- Modify: `Bowling/Features/Stats/StatsScreen.swift` (replace the placeholder)

**Interfaces:**
- Consumes: Tasks 1–3.
- Produces (views only):
  - `StatsScreen`: `ScrollView` on Canvas; `StatsFilterBar` pinned at the top
    (`.safeAreaInset(edge: .top)`), then `StatsCardView` per card, 16 pt margins, 10 pt
    between cards. On `.task(id:)` keyed on a small `Hashable` struct of `app.revision` and `app.statsFilter`: `app.statsFilter = StatsFilterDraft.current(app.statsFilter, in: app.store)`,
    report = `StatsEngine.report(games: store.stats.games(matching: filter, now: .now, calendar: .current), filter:)`,
    cards = `StatsCards.make(cards: StatsPreset.displayedStatsCards(layout: owner.statsLayout, profile: owner.statsProfile), report:)`.
    The always-present Canvas carries the `.task` (an empty view never runs it).
  - `StatsFilterBar`: the chips as capsules in a horizontal row; tap opens the sheet.
    VoiceOver: one button, label the chips joined by ", ", hint "Edit filters".
  - `StatsFilterSheet`: as spec §2. Edits a local copy; Done (disabled unless `canApply`)
    writes `app.statsFilter`; Cancel dismisses.
  - `StatsCardView`: Surface card (14 pt corners, 12/14 pt padding) with the title in
    `.monoLabel()`; `.tile` → `StatTile` plus footnote; `.notApplicable`/`.comingSoon` →
    the text in InkMuted; `.trend` → `TrendCard`; `.leaves` → `LeavesCard`; `.leftMost` →
    one `LeaveDiagramView(size: .regular)` row or the "No leave seen 3 times yet." text.
  - `TrendCard`: Swift Charts `LineMark` + `PointMark` for session averages (Accent), a
    dashed `LineMark` for the rolling average (InkMuted); one accessibility element with
    `TrendContent.accessibilityLabel`.
  - `LeavesCard`: the first 10 rows, then a "Show all N leaves" button that expands in
    place; each row is one accessibility element.

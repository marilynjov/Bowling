# Scoring (score one game) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Scoring placeholder with a screen that scores one game pin by pin, in count mode, or as a final score, saving every roll.

**Architecture:**
- **Pure rules:** `RollPad` holds one roll's entry rules (what the deck starts as, what each button records, when Strike and Spare are offered).
- **One model per open game:** an `@Observable` `ScoringModel` holds the game and its pad and records each roll through `app.write`.
- **Settings and views:** `ScoringSettings` reads two on-device settings. SwiftUI views render the model, and the root's full-screen cover shows `ScoringScreen`.

**Tech Stack:** SwiftUI, Swift Testing, BowlingData (`GameRepository`, `BallRepository`, `SessionRepository`), BowlingCore (`Scorer`, `RollPosition`, `PinSet`, `Scorecard`), #5's `PinDeckView` and `ScorecardStrip`.

**Spec:** `docs/superpowers/specs/2026-10-19-scoring-design.md`

## Global Constraints

- **Platform:** iOS 18 minimum; `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` and member import visibility, so import every module whose types a file uses.
- **Contract only, no package changes:**
  - `games.game(_:)`, `recordRoll(_:ballID:in:)`, `undoLastRoll(in:)`, `setEntryMode(_:for:)`, `clearRolls(in:)`, `setFinalScore(_:for:)`
  - `balls.activeBalls()`, `sessions.session(_:)`
  - `Scorer.scorecard(for:)`, `Scorer.nextRoll(in:)`
- **Contract facts the plan relies on:**
  - `recordRoll`'s `ballID: nil` means no ball.
  - `setEntryMode` throws `.entryModeLocked` once the game has rolls.
  - Saving a game recomputes `finalScore`/`isComplete` for scored modes, so switching a typed final-only game to pin by pin resets both.
  - `Scorer.nextRoll` is nil for every final-only game.
  - `undoLastRoll` on a game with no rolls returns it unchanged.
- **Colors:** D1 only through asset symbols (`.canvas`, `.surface`, `.hairline`, `.ink`, `.inkMuted`, `.accent`, `.accentText`).
- **Copy, exactly as the spec:**
  - Title "Game <n> · <name>".
  - Mode menu: "Pin by pin", "Count", "Final score", "Clear rolls…".
  - Clear rolls confirmation: "Clear all rolls in this game?" with "Clear rolls" and "Cancel".
  - Discard confirmation: "Discard the score of <n>?" with "Discard" and "Cancel".
  - Buttons: "Strike", "Spare", "Miss", "Foul", "Undo", "Next", "Save", "Done", "Change score".
  - Ball chip: "No ball". Complete panel: "Game complete".
  - VoiceOver: ball chip "Ball, <name>".
- **Settings keys** (on-device `UserDefaults`, never the synced store): `scoring.tapWhatFell` and `scoring.autoAdvanceOnSpare`, both default false.
- **Layout:** tap targets of at least 48 pt. Previews are `#if DEBUG`, in light, dark and AX5.
- **Tests:**
  - Run on iPhone 18 Pro Max (`id=2C568C51-3721-4FB2-90EE-D54EB3308C03`) with `-parallel-testing-enabled NO`, never on the iPhone 18 Pro.
  - Use `BowlingStore(inMemory: true)` and `UserDefaults(suiteName: "test.\(UUID())")!`.
  - Never `pkill -f` a pattern that matches your own command line; to stop a hung xcodebuild, kill its PID from `pgrep -x xcodebuild`.

Test command (whole suite): `xcodebuild test -scheme Bowling -destination 'id=2C568C51-3721-4FB2-90EE-D54EB3308C03' -parallel-testing-enabled NO`. One suite: add `-only-testing:BowlingTests/<Suite>`. Runs take several minutes; use `run_in_background`.

## Review Focus

1. **An open tenth frame** (for example 7 then 2) ends the game with no third box. Task 3: `openTenthEndsTheGame`.
2. **A count-mode second ball after 7:** the pad offers 0 through 3, and Spare records 3. Task 2: `countSecondBall`.
3. **A foul on a second ball** scores 0 and ends the frame. Task 3: `secondBallFoulEndsTheFrame`.
4. **Undo before the first roll** is disabled and does nothing. Task 3: `undoBeforeFirstRollDoesNothing`.
5. **Opening a game that is already complete** (later from History) shows the Complete panel and Undo. Task 3: `openingACompleteGameShowsComplete`.

**Ruling, a gap in the spec:** a final-only game has no rolls, so Undo can't reach its typed score. Its Complete panel gets **Change score**, which shows the score field again, prefilled. It's one button, and without it a typo is a dead end until History (#9).

### Task 2: RollPad

**Files:**
- Create: `Bowling/Features/Scoring/RollPad.swift`
- Test: `BowlingTests/Scoring/RollPadTests.swift`

**Interfaces:**
- Produces:

```swift
struct RollPad: Hashable {
    let position: RollPosition
    let entryMode: EntryMode          // .pinByPin or .countOnly
    let tapWhatFell: Bool
    let autoAdvanceOnSpare: Bool
    /// Pins the deck shows standing after this roll. Empty, or position.standingPins with tapWhatFell.
    private(set) var shown: PinSet
    init(position: RollPosition, entryMode: EntryMode, settings: ScoringSettings)
    init(position: RollPosition, entryMode: EntryMode, tapWhatFell: Bool, autoAdvanceOnSpare: Bool)
    /// The deck's binding setter; marks the pad as touched.
    mutating func setShown(_ pins: PinSet)
    var nextInput: RollInput           // .pinsLeft(shown)
    var offersStrike: Bool             // position.isFreshRack
    var offersSpare: Bool              // !position.isFreshRack
    var strikeInput: RollInput         // pin: .pinsLeft([]); count: .count(10)
    var spareInput: RollInput          // pin: .pinsLeft([]); count: .count(position.standingCount)
    var missInput: RollInput           // pin: .pinsLeft(position.standingPins); count: .count(0)
    var countChoices: ClosedRange<Int> // 0...position.standingCount
    /// tapWhatFell && autoAdvanceOnSpare && !isFreshRack && touched && shown.isEmpty
    var autoAdvances: Bool
}
```

Build positions in tests with `Scorer.nextRoll(in:)` over `GameRecord(gameIndex: 1, entryMode:, finalScore: 0, isComplete: false, frames:, sessionDate: .now, eventType: .practice)`. The frames are made of `FrameRecord(frameIndex:rolls:)`; check `RollRecord`'s init in BowlingCore `Records.swift`.

- [ ] **Step 1: Write the failing tests:**
  - `deckStartsEmptyByDefault`: frame 1 ball 1 gives `shown == []` and `nextInput == .pinsLeft([])`.
  - `deckStartsFullWithTapWhatFell`: `shown == .all`.
  - `nextRecordsWhatIsShown`: `setShown([7, 10])` gives `nextInput == .pinsLeft(PinSet(pins: [7, 10]))`.
  - `strikeOnlyOnAFreshRack`: true on frame 1 ball 1, on frame 10 ball 2 after a strike, and on frame 10 ball 3 after a spare. False on frame 1 ball 2 after 7, which has `offersSpare` true instead.
  - `pinInputs`: after 7 pins fell, leaving 4, 7 and 10, `missInput == .pinsLeft([4, 7, 10])`, and `spareInput == .pinsLeft([])`.
  - `countSecondBall`: count mode after `.count(7)` gives `countChoices == 0...3` and `spareInput == .count(3)`. A fresh rack has `strikeInput == .count(10)`.
  - `autoAdvanceNeedsTapWhatFell`: with both settings on, on ball 2, `setShown([])` makes `autoAdvances` true. Before any `setShown` it's false. With `tapWhatFell` false it's always false, and on a fresh rack it's always false.

### Task 3: ScoringModel, rolls

**Files:**
- Create: `Bowling/Features/Scoring/ScoringModel.swift`
- Test: `BowlingTests/Scoring/ScoringModelTests.swift`

**Interfaces:**
- Consumes: `RollPad` (Task 2), `app.scoringSettings` (Task 1), `ScoringTarget`.
- Produces:

```swift
@Observable final class ScoringModel {
    let target: ScoringTarget
    private(set) var game: GameRecord
    private(set) var scorecard: Scorecard
    /// Nil when the game is complete or final-only.
    var pad: RollPad?
    private(set) var balls: [BallSummary]
    private(set) var bowlerName: String
    /// This roll's ball when picked; nil uses game.defaultBallID.
    private(set) var ballOverride: BallID?
    /// Complete: rolls finished, or a final-only game with its score saved.
    var isComplete: Bool
    var canUndo: Bool                  // game has any roll
    var rollBallID: BallID?            // ballOverride ?? game.defaultBallID
    /// - Throws: `.notFound` for a missing session or game.
    init(target: ScoringTarget, app: AppModel) throws
    func next(); func strike(); func spare(); func miss(); func foul(); func count(_ pins: Int)
    func undo()
    func pickBall(_ id: BallID?)
    /// The deck binding: setShown, then next() when pad.autoAdvances.
    func setShown(_ pins: PinSet)
}
```

Actions catch errors into `app.error`. Each write goes through `app.write`, then reloads `game` via `games.game(target.gameID)`, recomputes the scorecard and pad (a fresh `RollPad` from `Scorer.nextRoll`), and sets `ballOverride = nil`. `bowlerName` comes from `sessions.session(target.sessionID)`: the bowler whose games contain `target.gameID`. Keep `app` as a stored property.

Test setup: an `AppModel` over an in-memory store and test `UserDefaults` (for both `sessionDefaults` and `scoringSettings`), an owner "Sam", two balls added with `balls.addBall(name:weightPounds:intendedRole:brand:)` (check its signature), and a helper `start(_ mode: EntryMode, ball: BallID? = nil) throws -> ScoringModel` using `startSession(SessionMetadata(date: .now, eventType: .practice), bowlers: [(sam.id, ball)], entryMode: mode)`.

- [ ] **Step 1: Write the failing tests:**
  - `strikeAdvancesToFrame2`: `strike()` makes `pad?.position.frameIndex == 2`, `scorecard.frames[0].marks == [.strike]`, and leaves `app.revision` higher.
  - `spareFromTheDeck`: `setShown([7, 10])`, `next()`, `spare()` gives frame 1 marks `[.count(8), .spare]`.
  - `firstBallFoulThenTenIsASpare`: `foul()`, then `spare()` gives frame 1 marks `[.foul, .spare]`.
  - `secondBallFoulEndsTheFrame`: count mode, `count(7)`, `foul()` gives the pad on frame 2 and frame 1 total 7.
  - `undoReopensTheLastRoll`: `strike()`, `undo()` gives the pad on frame 1 ball 1 and `canUndo == false`.
  - `undoBeforeFirstRollDoesNothing`: `canUndo == false`, and `undo()` leaves `app.revision` unchanged and `app.error == nil`.
  - `twelveStrikesIs300`: 12 × `strike()` gives `isComplete`, `pad == nil` and `scorecard.finalScore == 300`. Then `undo()` gives `!isComplete` and the pad on frame 10 ball 3.
  - `openTenthEndsTheGame`: count mode, 9 × (`count(0)`, `count(0)`), then `count(7)`, `count(2)` gives `isComplete` and final score 9.
  - `fullCountGame`: count mode, 9 × (`count(9)`, `count(0)`), then `count(10)`, `count(10)`, `count(10)` gives `isComplete` and final score 111.

  - `openingACompleteGameShowsComplete`: finish 12 strikes, make a new model on the target, and get `isComplete` and `canUndo`.

**Interfaces:**

- [ ] **Step 1: `ScoringScreen(target:)`.**
  - **Model:** `@State var model: ScoringModel?`, made in `.task` with `try ScoringModel(target:app:)`. On throw, set `app.error` and call `app.closeScoring()`.
  - **Navigation:** a `NavigationStack` with the inline title "Game \(game.gameIndex) · \(bowlerName)". Close is the leading toolbar item, keeping today's 48 pt close action (`app.closeScoring`). `EntryModeMenu` is trailing.
  - **Body:** a `ScrollView` on `.canvas` holding `ScorecardStrip` (current frame `pad?.position.frameIndex`), then one of:
    - pin by pin: `PinDeckView`, with the binding `Binding(get: { pad.shown }, set: model.setShown)` and `available: pad.position.standingPins`
    - count: `CountPad`
    - final-only and not complete, or editing: `FinalScoreEntry`
    - complete: `GameCompletePanel`
  - **Below the entry:** `ShortcutBar` when not complete and not final-only, and **Next** (`.borderedProminent`, full width, `.controlSize(.large)`) for pin by pin.
- [ ] **Step 2: Pieces.**
  - **`CountPad`:** a 3-column `LazyVGrid` of 0…10 (10 alone on the last row), each at least 48 pt. Numbers outside `countChoices` are disabled. A tap calls `model.count(n)`.
  - **`FinalScoreEntry`:** a number-pad field, focused on appear, prefilled when editing. **Save** is disabled while `QuickScoreEntry.score(text) == nil`.
  - **`ShortcutBar`:**
    - **Buttons:** Strike (when `offersStrike`), Spare (when `offersSpare`), Miss, Foul, Undo (disabled unless `canUndo`), and `BallChip`.
    - **Layout:** one `HStack`, or a two-row grid when `dynamicTypeSize.isAccessibilitySize`.
  - **`BallChip`:** a `Menu` with "No ball" and `balls`, a checkmark on `rollBallID`, label `BallPicker.label` or "No ball", and VoiceOver label "Ball, <name>". It's hidden for final-only games.
  - **`EntryModeMenu`:**
    - **Mode buttons:** the three modes with a checkmark, disabled unless `canChangeEntryMode`.
    - **When locked:** a "Clear rolls…" button, which shows a `confirmationDialog` "Clear all rolls in this game?" with "Clear rolls" (destructive) calling `model.clearRolls()`.
    - **Typed final score:** picking a mode while `discardsTypedScore` shows "Discard the score of \(score)?" with "Discard" (destructive) calling `setEntryMode`.
  - **`GameCompletePanel`:**
    - **Content:** "Game complete", the score in `.scoreHero`, and **Done** (`.borderedProminent`, which calls `app.closeScoring()`).
    - **Undo:** shown when `canUndo`.
    - **Change score:** shown for final-only games, and sets `isEditingFinalScore = true`.

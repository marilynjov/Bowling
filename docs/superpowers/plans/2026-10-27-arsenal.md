# Arsenal 1a Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Arsenal tab: active balls with name, weight, role and games bowled, and an
add form (name, weight, role, brand) whose ball shows up in New session and Scoring.

**Architecture:** Pure value types (`ArsenalList`, `BallDraft`) are built from
`BallRepository` and unit tested; the views only render them. The add sheet is driven by
`AppModel.isAddingBall` so the shared error alert knows it is topmost.

**Tech Stack:** SwiftUI (iOS 18, `@Observable`, MainActor default isolation), Swift
Testing, BowlingCore/BowlingData contract.

**Spec:** `docs/superpowers/specs/2026-10-27-arsenal-design.md`

## Global Constraints

- The app talks to packages only through the contract (AGENTS.md). No package edits on
  this branch; `Packages/` is Santiago's.
- Every write goes through `app.write`; failures go to `app.error` and the topmost
  screen's `sharedErrorAlert`.
- Copy is fixed by the spec: "15 lb · Strike", "15 lb" (unknown role), "12 games",
  "1 game", "No games yet", "No balls yet.", "Add ball", "Name", "Brand", "Weight",
  "Choose", "Role", "Strike", "Spare", "Both", "Cancel", "Save".
- VoiceOver strings live in `AccessibilityText` and are unit tested: "Phaze, 15 pounds,
  strike, 12 games"; "no games yet" for zero; the role left out when unknown.
- Each screen has Light, Dark and AX5 previews.
- Test command (never the iPhone 18 Pro named destination):
  `xcodebuild test -scheme Bowling -destination 'id=2C568C51-3721-4FB2-90EE-D54EB3308C03' -parallel-testing-enabled NO -only-testing:BowlingTests/<Suite> > .superpowers/sdd/2026-10-27-arsenal/<suite>.log 2>&1; tail -40 <log>`.
  If xcodebuild hangs after the tests pass, kill it by PID from `pgrep -x xcodebuild`,
  never `pkill -f`.
- Commits: the user commits. Each commit step gives the exact `git add` and
  `git commit -m` lines; no `Co-Authored-By` trailer.
- New app files go in `Bowling/Features/Arsenal/`, new tests in `BowlingTests/Arsenal/`
  (synchronized folders, no pbxproj edits).

## Review Focus

1. A name of only spaces must keep Save disabled, and a saved name is trimmed
   ("  Phaze " → "Phaze"). Task 2 tests both.
2. A ball whose stored role is `.unknown` (newer app version) must not read "Unknown":
   the row shows "15 lb" and VoiceOver leaves the role out. Task 1 tests it.
3. A refused save (repository throws) keeps the sheet's values and adds nothing.
   Task 2 tests the throw and the unchanged ball count; Task 3 keeps the sheet open.
4. The error alert while adding must show from the sheet, not the root, or iOS drops it.
   Task 2 tests `showsError(in: .addBall)` against `.root`.
5. Retired balls stay out of the list. Task 1 tests it.

### Task 1: ArsenalList and the row's VoiceOver label

**Files:**
- Create: `Bowling/Features/Arsenal/ArsenalList.swift`
- Modify: `Bowling/Components/AccessibilityText.swift`
- Test: `BowlingTests/Arsenal/ArsenalListTests.swift`, `BowlingTests/Components/AccessibilityTextTests.swift`

**Interfaces:**
- Produces:
  ```swift
  struct ArsenalList: Hashable {
      struct Row: Hashable, Identifiable {
          var id: BallID
          var name: String
          var detail: String        // "15 lb · Strike" or "15 lb"
          var games: String         // "12 games" / "1 game" / "No games yet"
          var accessibilityLabel: String
      }
      var rows: [Row]
      static func load(from store: BowlingStore) -> ArsenalList   // activeBalls() order
      /// One row; `load` maps each `BallSummary` through it (`BallSummary` has no public init).
      static func row(id: BallID, name: String, weightPounds: Int, role: BallRole, gamesBowled: Int) -> Row
  }
  extension AccessibilityText {
      static func ballRow(name: String, weightPounds: Int, role: BallRole, gamesBowled: Int) -> String
  }
  ```
  Role words: Strike / Spare / Both (row), strike / spare / both (VoiceOver); `.unknown`
  is left out of both.

- [ ] **Step 1: Write the failing tests.** In-memory `BowlingStore(inMemory: true)`, balls

  - `rowsFollowNameOrder`: add "Zed", "Alpha" → `rows.map(\.name) == ["Alpha", "Zed"]`.
  - `detailShowsWeightAndRole`: 15 lb strike → `detail == "15 lb · Strike"`.
  - `gameCountWording`: zero games → "No games yet". For 1 and 12, start sessions with the
    ball as default (as `NewSessionDraftTests.startCreatesOneGamePerBowlerInLineupOrder`

  - `AccessibilityTextTests.ballRowReadsEveryPart`: `ballRow(name: "Phaze", weightPounds: 15, role: .strike, gamesBowled: 12) == "Phaze, 15 pounds, strike, 12 games"`.
  - `ballRowWithNoGames`: … `gamesBowled: 0` → "Phaze, 15 pounds, strike, no games yet".
  - `ballRowLeavesOutAnUnknownRole`: `.unknown`, 1 game → "Phaze, 15 pounds, 1 game".
  - In `ArsenalListTests`, `unknownRoleShowsOnlyTheWeight`:
    `ArsenalList.row(id: BallID(), name: "Phaze", weightPounds: 15, role: .unknown, gamesBowled: 1)`
    → `detail == "15 lb"` and `accessibilityLabel == "Phaze, 15 pounds, 1 game"`.

### Task 3: The Arsenal screens

**Files:**
- Create: `Bowling/Features/Arsenal/AddBallSheet.swift`
- Modify: `Bowling/Features/Arsenal/ArsenalScreen.swift` (replace the placeholder)

**Interfaces:**
- Consumes: `ArsenalList.load(from:)`, `BallDraft`, `app.isAddingBall`, `.addBall`.
- Produces (views only):
  - `ArsenalScreen`: `List` of `ArsenalList.rows` (name in `.headline`, then `detail` and
    `games` in secondary text), each row one accessibility element with
    `row.accessibilityLabel`. Toolbar **+** (`Label("Add ball", systemImage: "plus")`)
    sets `app.isAddingBall = true`. Empty: `ContentUnavailableView` "No balls yet." with
    an **Add ball** button. Reloads in `.task(id: app.revision)`.
    `.sheet(isPresented: $app.isAddingBall) { AddBallSheet() }`.
  - `AddBallSheet`: `NavigationStack` + `Form` titled "Add ball". `@State var draft = BallDraft()`.
    Name and Brand text fields; Weight `Picker` with a "Choose" nil tag then 6…16 as
    "15 lb"; Role segmented `Picker` (Strike / Spare / Both). Cancel sets
    `app.isAddingBall = false`. Save (disabled unless `draft.canSave`) runs
    `try app.write { try draft.save(to: $0) }`, then `app.isAddingBall = false`; on throw
    sets `app.error = error` and stays. `.sharedErrorAlert(in: .addBall)`.
